Movie Review Website

A web application built with Python and Django that allows users to explore movies, share reviews, rate films, and interact with other users.

Features

• User registration and login
• User profiles
• Movie reviews and ratings
• Comments and likes
• Interactive user experience

Technologies

• Python
• Django
• SQLite
• HTML
• CSS

About the Project

This project was developed as a personal project to improve my Python and Django skills and gain practical experience in web development.
